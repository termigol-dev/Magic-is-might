# Magic Is Might

Web estática del juego de rol Magic Is Might. Incluye un prototipo de atlas interactivo de Hogwarts y secciones futuras de ingredientes y pociones.

## Publicación en Vercel

1. Sube el contenido de esta carpeta a la raíz del repositorio `Magic-is-might` de GitHub.
2. En Vercel selecciona **Add New → Project → Import Git Repository**.
3. Selecciona el repositorio. Framework Preset: **Other**. Build Command: **vacío**. Output Directory: **vacío** (raíz del repositorio).
4. Pulsa **Deploy**.

El proyecto no requiere instalación, backend ni dependencias. Si Vercel requiere una carpeta de salida, utiliza `.`.

## Aviso

El mapa ilustrado actual y la ubicación de los marcadores son provisionales y no están verificados arquitectónicamente. No se deben utilizar aún como rutas de juego.
